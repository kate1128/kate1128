# Gradio 快速构建 AI 应用界面

> [Gradio](https://www.gradio.app/) 是一个 Python 库，让你用几行代码就能为 ML 模型或 LLM 应用创建 Web 交互界面。无需写 HTML/CSS/JavaScript。

---

## 是什么

Gradio 的核心价值：**把"模型效果展示"从 Jupyter Notebook 里拿出来，变成任何一个同事都能在浏览器里操作的 Demo**。

```python
import gradio as gr

def greet(name):
    return f"Hello {name}!"

gr.Interface(fn=greet, inputs="text", outputs="text").launch()
# 访问 http://localhost:7860 即可看到界面
```

## 为什么用 Gradio

- LLM 应用在 Demo 阶段的标配工具——构建 MVP 快、分享方便
- 提供 `gr.ChatInterface` 组件，一行代码就能创建聊天界面
- 支持 Hugging Face Spaces 一键部署，生成公开链接
- 与 LangChain/LlamaIndex 集成方便

## 常见应用场景

| 场景 | 关键组件 | 复杂度 |
| --- | --- | --- |
| 简单 NLP（摘要/NER） | `gr.Interface` + text input/output | ⭐ |
| 聊天机器人 | `gr.ChatInterface` + `gr.ChatMessage` | ⭐⭐ |
| 图文互转 | `gr.Image` + `gr.Textbox` | ⭐⭐ |
| 知识库问答 | ChatInterface + 文件上传 + RAG 后端 | ⭐⭐⭐ |

## Gradio vs Streamlit

| | Gradio | Streamlit |
| --- | --- | --- |
| 最适合 | ML 模型 Demo、快速原型 | 数据仪表盘、较复杂的 Web 应用 |
| Chat 组件 | 原生支持 `ChatInterface` | 需要 `st.chat_message`（较新） |
| 部署 | Hugging Face Spaces 一键 | Streamlit Cloud |
| 学习曲线 | 极低 | 低 |

**建议**：纯 Demo 用 Gradio，需要更多自定义逻辑/页面用 Streamlit。
