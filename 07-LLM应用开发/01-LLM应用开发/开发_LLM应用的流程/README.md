# LLM 应用开发流程总览

> 从零到一构建一个 LLM 应用的完整流程。从项目规划到数据准备，从模型集成到部署上线。

---

## 整体流程

```
项目规划 → 数据准备 → 大模型集成 → 核心功能实现 → 迭代优化 → 前端界面 → 部署上线 → 维护改进
```

---

| 环节 | 核心内容 | 详细笔记 |
| --- | --- | --- |

| 2. 数据准备 | 文档加载、文本分割、向量化、入库 | [02-数据准备与向量知识库构建](02-数据准备与向量知识库构建.md) |
| 3. 大模型集成 | 接入 GPT/星火/文心/GLM 等 API，编写调用代码 | 待扩充 |
| 4. 核心功能实现 | Prompt Engineering、流式回复、多轮对话、历史记录 | 待扩充 |
| 5. 迭代优化 | 验证评估、收集 Bad Case、迭代 Prompt 和检索策略 | 待扩充 |
| 6. 前端界面 | Gradio / Streamlit 搭建，文档上传，知识库选择 | [Gradio 概述](../应用案例/Gradio_友好界面演示/概述.md) |
