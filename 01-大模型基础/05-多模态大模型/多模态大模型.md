# 多模态大模型

> AI 正在从"只能读文字"进化到"能看、能听、能说"。多模态大模型是这一进化的核心——它将文本、图像、音频、视频等多种信息形式统一到一个模型中处理。

---

## 一、什么是多模态

**单模态模型**：只能处理一种类型的数据。GPT-4（纯文本版）只能理解文字，ResNet 只能识别图片。

**多模态模型**：能同时理解多种类型的数据。你给它一张菜单的照片，它能告诉你"这家店有什么菜、人均多少钱"——这需要同时理解图像（菜单照片）和文本（菜品名称和价格）。

## 二、典型的多模态模型

| 模型 | 模态 | 核心能力 | 代表应用 |
| --- | --- | --- | --- |
| **GPT-4o / GPT-4V** | 文本 + 图像 + 音频 | 看图回答问题、图表分析、OCR 提取 | ChatGPT 的图片理解功能 |
| **Claude 3.5 Sonnet** | 文本 + 图像 | PDF/截图/文档理解超强 | 文档分析、代码审查 |
| **Gemini 1.5 Pro** | 文本 + 图像 + 音频 + 视频 | 1M+ 上下文，直接分析视频 | 视频内容理解 |
| **DALL-E 3 / Midjourney** | 文本 → 图像 | 文生图 | AI 绘画 |
| **Sora** | 文本 → 视频 | 文生视频 | 视频生成 |

## 三、核心技术架构

### 视觉编码器 + LLM + 适配器

目前最主流的多模态架构模式：

```
图像 → 视觉编码器（ViT/CLIP）→ 图像特征向量
                                          ↓
                              适配器（投影层/交叉注意力）
                                          ↓
文本 → Token化 → Embedding ──────→ LLM ──→ 输出
```

### 关键组件

- **ViT（Vision Transformer）**：把图像切成小块（Patch），像处理文本 Token 一样处理图像块
- **CLIP（Contrastive Language-Image Pre-training）**：用对比学习让图像和文本在同一个向量空间中对齐——"猫的照片"和"cat"这个词距离很近
- **BLIP-2**：用一个轻量级的 Q-Former（Query Transformer）作为视觉编码器和 LLM 之间的"翻译器"，大幅降低了训练成本

## 四、为什么重要

- **更自然的交互**：人类本来就是多模态的——说话时打手势、看菜单时读文字。多模态 AI 让交互更贴近人类自然行为
- **更广阔的应用**：医疗影像分析（CT + 病历）、自动驾驶（摄像头 + 雷达 + 地图）、教育（课本扫描 + 答疑）
- **更强的理解力**：纯文本模型只能"听说"，多模态模型能"看到"——这对理解物理世界至关重要

## 五、发展现状与挑战

| 现状 | 挑战 |
| --- | --- |
| 图文理解已成熟（GPT-4V/Claude 效果很好） | 视频理解还在早期（计算量巨大） |
| 文生图已商用（Midjourney/DALL-E） | 文生视频还在 Demo 阶段 |
| 多模态 Agent 开始出现（能看屏幕操作软件） | 不同模态的深度融合仍待突破 |
| 开源多模态模型在追赶（LLaVA/Qwen-VL） | 训练成本是纯文本模型的数倍 |
