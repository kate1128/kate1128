# 大模型与 Transformer

> Transformer 是 LLM 的"引擎"。理解它为什么比 RNN 好、以及自注意力机制怎么工作的，是理解整个 LLM 技术栈的起点。

---

## 一、Transformer 之前：RNN 的困境

在 Transformer 出现之前，语言模型的主流架构是循环神经网络（RNN/LSTM/GRU）：

```
输入："我 爱 北京 天安门"
RNN 处理：词1 → 词2 → 词3 → 词4  （必须按顺序来！）
```

**RNN 的三个致命缺陷**：
1. **无法并行**：处理每个词都要等上一个词处理完——训练慢得要命
2. **长距离遗忘**：离得越远的词，对当前位置的影响越小——第 1000 个词和开头第一句的关系几乎丢失
3. **梯度消失/爆炸**：深层网络的反向传播中梯度容易变成 0 或者无穷大

## 二、Transformer 的核心创新

Transformer 用两个机制解决了 RNN 的问题：

### 自注意力机制（Self-Attention）

**核心思想**：让句子中的每个词都能"看到"所有其他词，并决定该"关注"哪些词。

```
句子："那个男孩没有吃蛋糕，因为他已经饱了"
问题：代词"他"指代谁？
答案："男孩"——但 RNN 在读到"他"时，前面十几个词的信息已经衰减了。

Transformer 的做法：
  每个词同时看所有词 → 计算注意力分数 → "他"和"男孩"的注意力最高
```

### 位置编码（Positional Encoding）

自注意力本身不知道词的顺序——"我爱你"和"你爱我"的注意力矩阵是一样的。位置编码给每个位置注入一个独特的向量信号，让模型知道词的顺序。

## 三、Transformer 的架构

```
输入文本 → Token化 → Embedding + 位置编码
                            ↓
              ┌─────────────────────────┐
              │   Encoder（编码器）×N层    │
              │   - 自注意力              │
              │   - 前馈网络              │
              │   - 层归一化              │
              └─────────────────────────┘
                            ↓
              ┌─────────────────────────┐
              │   Decoder（解码器）×N层    │
              │   - 掩码自注意力          │
              │   - 交叉注意力（看Encoder）│
              │   - 前馈网络              │
              └─────────────────────────┘
                            ↓
                   线性层 + Softmax → 下一个Token
```

> GPT 系列只用了 Decoder 部分（因为任务是生成文本，不需要 Encoder）。
> BERT 只用了 Encoder 部分（因为任务是理解文本，不需要生成）。

## 四、为什么"大"是关键

Transformer 的成功 = **架构创新 + 规模扩展（Scaling）**：

| | GPT-1 | GPT-2 | GPT-3 | GPT-4 |
| --- | --- | --- | --- | --- |
| 参数 | 0.1B | 1.5B | 175B | 未公开 |
| 层数 | 12 | 48 | 96 | 未公开 |
| 关键发现 | 预训练+微调有效 | **规模越大越好** | 涌现能力 | 多模态推理 |

架构是骨架，规模是肌肉。Transformer 提供了一个灵活可扩展的架构，而 Scaling Law 告诉我们：只要堆足够多的数据和参数，能力就会持续提升。
