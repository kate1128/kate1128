# 大语言模型发展历史

> 从 2017 年 Transformer 论文发表至今，LLM 的发展可以划分为四个阶段。五年不到的时间，模型从"玩具"进化为"基础设施"。

---

## 一、时间线概览

| 时间 | 里程碑 | 意义 |
| --- | --- | --- |
| 2017 | Transformer 论文（"Attention Is All You Need"） | LLM 的技术基石诞生 |
| 2018 | BERT、GPT-1 | 预训练 + 微调范式的开端 |
| 2019 | GPT-2（1.5B） | OpenAI 因"太危险"不敢开源，引发广泛讨论 |
| 2020 | GPT-3（175B） | 涌现能力的首次展示，In-Context Learning 震惊学界 |
| 2022.11 | ChatGPT 发布 | 2 个月达到 1 亿用户，历史上增长最快的应用 |
| 2023.2 | LLaMA（Meta）开源 | 开源大模型的转折点 |  
| 2023.3 | GPT-4 发布 | 多模态 + 推理能力大幅跃升 |
| 2023-2024 | 开源浪潮：LLaMA 2/3、Mistral、DeepSeek、Qwen | 开源模型性能逼近闭源 |
| 2024-2025 | 多模态融合 + Agent + MCP | LLM 从"聊天"走向"做事" |

## 二、四个发展阶段

### 阶段 1：预训练时代（2017-2019）

Transformer 架构解决了 RNN 无法并行和长距离依赖的问题。BERT 证明了"大规模预训练 + 下游微调"范式的强大。但这一阶段还需要为每个任务单独微调模型。

### 阶段 2：规模竞赛（2020-2022）

OpenAI 的 GPT-3 将参数从 1.5B 拉到 175B，展示了"大规模 = 新能力"的 Scaling Law。主要玩家都在堆参数、堆数据。

### 阶段 3：指令对齐（2022-2023）

ChatGPT 证明了"光有知识不够，还要听得懂人话"。RLHF（人类反馈强化学习）成为标配。模型不再只是"续写文本"，而是"理解和执行指令"。

### 阶段 4：Agent 化与多模态（2024-至今）

LLM 从"能说"到"能干"——Function Calling、Tool Use、MCP 协议让 LLM 成为行动的枢纽。多模态让 LLM 能"看"图和"听"声音。Agent 框架让 LLM 自主规划和执行多步任务。

## 三、关键趋势

- **参数竞赛结束，推理竞赛开始**：不再比谁的模型参数多，而是比谁的推理效率高、成本低
- **开源逼近闭源**：LLaMA 3、DeepSeek-V3、Qwen 2.5 等开源模型效果接近 GPT-4，改变了产业格局
- **从"大"到"小"**：MoE（混合专家）架构让小模型拥有大能力；量化技术让 7B 模型在手机上跑
- **Agent 是下一个前沿**：模型不再只是回答问题，而是自主完成复杂任务
