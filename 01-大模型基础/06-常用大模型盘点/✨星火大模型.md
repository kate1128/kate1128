# 讯飞星火大模型

> 科大讯飞开发的语言大模型，以**中文语音和语言处理能力**见长，是国内重要的 LLM 产品之一。

## 基本情况

- **开发者**：科大讯飞（iFLYTEK）
- **首次发布**：2023 年 5 月（V1.0），后续持续迭代至 V4.0+
- **使用地址**：[xinghuo.xfyun.cn](https://xinghuo.xfyun.cn)
- **核心优势**：中文语音识别与合成 + 语言理解——讯飞在语音领域深耕 20+ 年

## 主要版本

| 版本 | 发布时间 | 主要升级 |
| --- | --- | --- |
| V2.0 | 2023.08 | 多模态能力（图片理解） |
| V3.0 | 2023.10 | 全面对标 GPT-3.5 |
| V3.5 | 2024.01 | 语言理解、生成、问答等七方面升级，支持 System 指令和插件调用 |
| V4.0+ | 2024+ | 推理和编程能力增强 |

## 特点

- 中文语音交互是其核心差异化能力（讯飞输入法、讯飞听见等产品的技术积淀）
- API 提供语音识别/合成 + 大模型的一体化方案
- 支持 System Prompt 和插件（Function Calling）
- 在教育、司法、医疗等垂直行业有较深的场景积累
