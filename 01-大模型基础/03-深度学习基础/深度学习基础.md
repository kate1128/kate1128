# 深度学习基础：从 Python 机器学习到 Transformer 的必修地基

> 本笔记定位：凡是要学大语言模型（LLM）、要理解 Transformer、要做微调的朋友，都需要把这篇文章打底。它不讲花哨的东西，只讲清楚"神经网络是怎么把简单数学堆成智能"这件事的内核。读完之后建议接着看本库的《Transformer结构理解》和《大模型与Transformer》。

## 一、概念引入：机器学习是谁，深度学习又是谁

先说最朴素的定义。**机器学习（Machine Learning, ML）**是让程序从数据里"自己学规则"而不是"人为写规则"的一套方法。传统编程是人把规则写好（if 数据满足某某条件就返回某某结果），机器学习则是人给程序大量"输入-输出"样例，让程序自己摸索出输入到输出的映射规律。

**深度学习（Deep Learning, DL）**是机器学习的一个子集，特指用"多层神经网络"来拟合这种映射的方法。它和传统机器学习最直观的区别有三个：

1. **特征的获取方式不同**：传统 ML（如决策树、SVM、逻辑回归）通常需要人工做特征工程，比如从文本里数词频、从图片里设计边缘算子；深度学习则是端到端学习，把原始数据（像素、token）直接喂进去，模型自动在内部逐层抽象出"低级特征 → 高级特征"。
2. **模型容量不同**：深度模型参数量巨大，动辄百万、十亿、千亿级，能记住非常复杂的分布；传统模型参数量小，通常几千到几十万。
3. **对算力和数据的需求不同**：某种程度上，传统 ML 是小数据小算力时代的产物，深度学习爆发则依赖 GPU 并行计算和大数据。

| 对比维度 | 传统机器学习 | 深度学习 |
| --- | --- | --- |
| 特征来源 | 人工特征工程为主 | 自动逐层学习表征 |
| 典型模型 | 线性回归、逻辑回归、SVM、决策树 | MLP、CNN、RNN、Transformer |
| 参数量级 | 千~百万级 | 百万~千亿级 |
| 强项场景 | 结构化表格数据、小样本、可解释性 | 图像、语音、自然语言等非结构化数据 |
| 训练方式 | 梯度下降或解析求解 | 反向传播 + 梯度下降及其变体 |

在 NLP 这条线上，历史演进大致是：词袋模型 → 词向量（Word2Vec/Glove）→ RNN/LSTM → 注意力机制 → Transformer → LLM。本文把深度学习地基（MLP、激活函数、损失函数、反向传播、优化器、正则化、PyTorch 实操）讲透，Transformer 才能真正读得懂。

## 二、为什么需要：不懂它，Transformer 全是魔法

很多人学 Transformer 时会有一种"它好像 f（x）就能出结果"的错觉。其实 Transformer 内部不外乎：**线性层（MLP）＋注意力（Attention）＋各类『上一个方块：激活函数、归一化、dropout』**。下面这些概念在 Transformer 里全都会再次出现：

- **线性变换/矩阵乘法**：Attention 里计算 Q、K、V 都要用到 `nn.Linear`，本质就是全连接层。
- **激活函数**：Transformer 的 FFN（前馈网络）用的是 ReLU 或 GELU。
- **损失函数（交叉熵）**：LLM 预训练和微调的核心损失，就是"下一个 token 预测"的交叉熵。
- **反向传播与自动求导**：`loss.backward()` 这一行背后的机制，就是本文第三、五节要讲的链式法则。
- **优化器（Adam/AdamW）**：大模型训练几乎清一色用 Adam 系优化器。
- **dropout / LayerNorm / 残差连接**：都是为了控制过拟合和训练稳定性。

换句话说，把本文吃透，后面看 Transformer 的每一层代码都会有"老朋友"的感觉。而且 PyTorch 的张量（tensor）和自动求导（autograd）更是所有大模型框架的运行基石。

## 三、核心原理：从感知机到 MLP，再到训练机制

### 3.1 感知机（Perceptron）——最古老也最本质的单神经元

感知机是 1958 年 Rosenblatt 提出的人工神经元，数学上就一行：

```
y = f( w1*x1 + w2*x2 + ... + wn*xn + b )
```

其中 x 是输入，w 是每个输入上的权重，b 是偏置，括号里的 w·x+b 叫"加权和"（仿射变换），f 是激活函数（当时是阶跃函数，输出 0 或 1）。感知机能拟合线性可分问题（如与或门），但 1969 年 Minsky 用 XOR 证明它连"异或"这种简单非线性任务都学不会，AI 第一次寒冬由此而来。

### 3.2 多层感知机（MLP）——把神经元堆成层，把层堆成网络

破解 XOR 的办法是引入**隐藏层**：一个输入层（2 个神经元）、一个隐藏层（例如 3 个神经元）、一个输出层（1 个神经元），层与层之间全连接。这就是**多层感知机（Multi-Layer Perceptron, MLP）**。

### 3.3 前向传播（Forward Propagation）：信息从输入流向输出

假设输入是一个 b 维向量 x，网络有 L 层。第 l 层的权重矩阵记作 W^{(l)}（形状：本层输出神经元数 × 上一层神经元数），偏置记作 b^{(l)}，激活函数记作 σ。前向传播就是一路做"线性 + 非线性"：

```
a^(1) = σl1( W^(1)·x + b^(1) )        # 第一隐藏层输出
a^(2) = σl2( W^(2)·a^(1) + b^(2) )     # 第二隐藏层输出
...
y_hat = σL( W^(L)·a^(L-1) + b^(L) )    # 最后输出层输出预测
```

整个过程可以理解为把输入 x 不断经历"旋转变换（乘 W）＋平移（加 b）＋非线性扭曲（σ）"，最终得到预测值 y_hat。因为每一层都是矩阵乘法，GPU 的并行能力可以在这里被充分利用，这也是 PyTorch 里写 `nn.Sequential` 时一步步 forward 的直观来源。

### 3.4 激活函数：为什么必须非线性

如果去掉激活函数，多层线性变换 `W2(W1·x+b1)+b2` 合并后仍然是一个线性函数，那"深"就没有意义了。只有引入非线性，网络才能真正表达任意复杂函数（通用近似定理：足够宽的单隐藏层网络可以逼近任意连续函数）。好用的激活函数要同时满足：**（a）几乎处处可导**，方便求梯度；（b）**梯度不能太接近 0**，否则反向传播时信息会消失。

常用激活函数对比：

| 函数 | 公式（粗略） | 输出范围 | 优点 | 问题/缺点 |
| --- | --- | --- | --- | --- |
| sigmoid | σ(z) = 1/(1+e^(-z)) | (0,1) | 输出可解释为概率，处处光滑可导 | 两端梯度饱和接近 0，**梯度消失**严重；输出非 0 均值，收敛慢；有指数运算 |
| tanh | tanh(z) = (e^z-e^(-z))/(e^z+e^(-z)) | (-1,1) | 0 均值输出，收敛比 sigmoid 快 | 两端同样饱和，**梯度消失**问题仍在 |
| ReLU | relu(z) = max(0, z) | [0, +∞) | 正区间梯度恒为 1，**计算简单、收敛快**、天然稀疏 | 负区间梯度恒为 0，**神经元"死亡"**：一旦某个单元更新后权重为负，之后就永远输出 0，梯度再也传不回来 |
| softmax | softmax(z)_i = e^(z_i)/Σ e^(z_j) | (0,1)且和为 1 | 多分类概率分布，配合交叉熵有数值稳定性 | 它不是逐元素非线性，而是对整个归一化向量操作的，通常只用在最后一层 |

一个关键点：**中间隐藏层首选 ReLU 系（ReLU/SiLU/GELU）**，因为梯度消失最小；**输出层按任务选择**——回归用恒等/线性，二分类用 sigmoid，多分类用 softmax。LLM 的 FFN 隐藏层用的就是 GELU/SiLU 这类平滑的 ReLU 变体，输出层（词表概率）用最后的 Linear 层直接映射。

### 3.5 损失函数：怎么评价预测得好不好

训练的目标是让预测值 y_hat 与真实值 y 的差距尽可能小，这个"差距"就是**损失（loss）**。两类最常用：

**（1）均方误差 MSE（Mean Squared Error）——适合回归**

```
MSE = (1/n) * Σ ( y_i - y_hat_i )^2
```

把误差平方后求和再平均。平方的好处是：误差大时惩罚陡增、处处可导。缺点一是单位变成了平方（不够直观），二是对极端离群点过于敏感（离群点的损失被平方放大很多）。回归任务（预测房价、温度、坐标）用它。

**（2）交叉熵 Cross Entropy——适合分类**

```
CE = -Σ y_i * log( p_i )      # y 是 one-hot 真实标签，p 是模型预测的概率
单样本（多分类）简化式： CE = -log( p_c )     # c 是真实类别下标
```

直观理解：模型给真实类别打出的概率 p_c 越接近 1，CE 越接近 0；越接近 0（自信地猜错），CE 越大。

**为什么分类必须用交叉熵而不是 MSE？** 有三层原因：

1. **分类的"真值"是一维 one-hot**，而模型输出的是一个概率分布，两者天然适合用"分布之间的距离"来度量。交叉熵衡量两个分布之间的不匹配程度，正好对应。
2. **导数形态好**：如果分类用 MSE，配合 softmax 输出，它关于 logits 的导数里会带一个（p_i - y_i)·σ'(z) 因子，而 softmax 饱和区的导数趋近 0，梯度会消失；交叉熵 + softmax 的梯度直接是 (p - y) 这个残差形式，误差越大梯度越大，学得快且稳。
3. **信息论意义**：交叉熵 = 熵 H(y) + KL 散度（真实分布与预测分布的不匹配度），最小化交叉熵等价于最小化 KL 散度。

### 3.6 反向传播与梯度下降：深度学习的发动机

模型训练可以抽象成三步循环：**前向计算损失 → 反向传播算梯度 → 沿着负梯度更新参数**。

**梯度下降（Gradient Descent）**是更新规则的本体：

```
w ← w - lr * ∂L/∂w
```

其中 lr 是学习率（步长），∂L/∂w 是损失对权重 w 的偏导数（梯度）。减去梯度方向，是因为梯度指向"损失上升最快"的方向，负方向就是损失下降的方向。

**反向传播（Backpropagation）**则是高效求解所有 ∂L/∂w 的算法，它的本质就是**链式法则的有序应用**。链式法则的数学形式：

```
若 L = L(a_L)，a_L = σ(a_{L-1})，a_{L-1} = W·x + b
则 ∂L/∂W = ( ∂L/∂a_L ) · σ'(a_{L-1}) · x^T
         = 后一层的"局部梯度" × 前一层的激活输入
```

其思路是：**从输出层往前，逐层地利用后面算好的梯度推前面层的梯度**。输出层的误差最容易算（损失对输出的偏导），而每一层的梯度可以写成"上一层梯度的函数"，于是只要从后往前扫描一遍，就能用一次前向 + 一次反向算出全部参数的梯度。这就是"反向"二字的由来——如果不这样做而是挨个参数独立近似数值求导，复杂度是参数量级，根本算不过来；反向传播让代价等于一次前向计算的规模。

在 PyTorch 里，这些都封装成 `loss.backward()` 一行。但注意：**backward 只是算梯度，真正改参数的是优化器的 `.step()`**。二者必须配合：`optimizer.zero_grad()` 清空旧梯度 → `loss.backward()` 回填新梯度 → `optimizer.step()` 更新参数。

### 3.7 优化器：梯度下降的升级迭代

朴素梯度下降（batch GD）把整个数据集算完才更新一次，太慢；改为每看一个样本就更新一次是 SGD（随机梯度下降，其实真正的随机）；工程上每个小批次更新一次叫 Mini-batch SGD。再往上做升级：

| 优化器 | 核心思想 | 特点/解决的问题 | 仍需留意的问题 |
| --- | --- | --- | --- |
| SGD | 直接按梯度方向更新 | 最简单，泛化性往往不错，收敛路径之字抖动 | 收敛慢，易入局部极小/鞍点，学习率难调 |
| Momentum（动量） | 更新时叠加"历史梯度的方向"：v ← μ·v - lr·g；w ← w + v | 惯性冲过平坦区，抖动减小、收敛加速 | 可能 Overshoot 越过极小点 |
| RMSProp / AdaGrad / AdaDelta | 按"梯度平方的滑动平均"自适应缩放每维学习率 | 对每个参数的步长自适应：梯度大则步子小，梯度小则步子大 | 分母累积可能过小导致步长爆炸 |
| Adam | Momentum + RMSProp 结合（一阶矩 + 二阶矩，并做偏差修正） | 同时有动量和自适应步长，对超参鲁棒，大模型标配 | 记忆开销约为参数的 2 倍（额外存 v、s）；早期学习率偏热需 warmup |

Adam 的更新可粗略写成（m、v 分别为一阶/二阶矩估计，β1、β2 为衰减系数，ε 防除零）：

```
m ← β1·m + (1-β1)·g
v ← β2·v + (1-β2)·g²
m_hat = m / (1 - β1^t)        # 偏差修正，t 是步数
w ← w - lr * m_hat / (√v_hat + ε)
```

**LLM 领域几乎都用 AdamW**（Adam + weight decay 解耦），因为它对大模型更稳。

### 3.8 过拟合与正则化：模型太聪明反而是坏事

如果网络参数太多、数据太少，模型会把训练集"背下来"而不是"学会规律"，表现是训练 loss 很低、测试集结果很差，这叫**过拟合（overfitting）**。反之模型学不动叫欠拟合。五大战斗常规武器：

1. **L1 正则化**：损失里加 λ·Σ|w|。惩罚让不重要的权重趋于 0，产生**稀疏解**，有特征选择效果。但 |w| 在 0 处不可导，优化略有麻烦。
2. **L2 正则化（权重衰减 weight decay）**：损失里加 (λ/2)·Σw²。让权重整体向 0 收缩但不会变成精确 0，防止个别权重过大导致模型对某特征过度敏感。对梯度贡献是 λ·w，等于每次更新都小幅"拉扯"权重，这就是"衰减"的由来。
3. **Dropout**：训练时以概率 p 随机把一些神经元输出置 0，让网络"不依赖某几个节点"，相当于在训练很多瘦身的子网络再集成。注意推理时要把所有输出乘以 (1-p)（或训练时除以 1-p），保持期望一致。
4. **数据增强（Data Augmentation）**：对原始输入做合法变换生成更多样本，如 NLP 里的回译、加噪、mask、同义词替换等。
5. **早停（Early Stopping）**：每个 epoch 在验证集上评估，一旦验证指标连续若干轮不升反降，立即停止训练，取验证集最优时的权重。

### 3.9 标准训练流程：数据 → 模型 → 损失 → 优化 → 评估

不管多大多小的网络，训练循环都长一个样：

```
for epoch in range(总轮数):
    打乱训练集 → 切成一个一个小批次 batch
    for x_batch, y_batch in 数据加载器:
        y_hat = model(x_batch)                        # ① 前向
        loss = loss_fn(y_hat, y_batch)                # ② 算损失
        optimizer.zero_grad()                          # ③ 清梯度
        loss.backward()                                # ④ 反向传播自动求梯度
        optimizer.step()                               # ⑤ 更新参数
    在验证集上评估（准确率/loss），记录最优模型 → 早停决策用
```

## 四、关键知识点：张量 tensor 与自动求导 autograd

**Tensor（张量）**：形状化的多维数组——0 维是标量、1 维是向量、2 维是矩阵、3 维及以上统称张量。它是 PyTorch 所有数据的基本盒子。看几个直观例子：

```python
import torch
x = torch.tensor([1.0, 2.0, 3.0])            # 1 维张量，形状 [3]
M = torch.randn(2, 3)                        # 2 维张量，形状 [2,3]
T = torch.randn(2, 3, 4)                     # 3 维张量 —— LLM 里常见：batch, seq_len, hidden
```

Transformer 里一个典型张量形状是 `[batch_size, seq_len, hidden_size]`，例如 [32, 512, 768]。张量的三大能力：**运算（加减乘矩阵乘）、变形（view/transpose/reshape）、搬运算设备（.cuda()/.to()）**。

**Autograd（自动求导）**：PyTorch 的"免费梯度"。凡是 `requires_grad=True` 的张量参与了运算，PyTorch 就会自动构建一张"计算图"（记录每一步操作），之后调用 `loss.backward()` 时，它自动按照计算图反向走一遍链式法则，把梯度填进各张量的 `.grad` 属性。参数由 `nn.Parameter` 包裹，天然 requires_grad=True。注意两点：每次迭代要 `optimizer.zero_grad()` 清零；推理时用 `torch.no_grad()` 或 `model.eval()` 省内存、防污染。

## 五、代码实践：PyTorch 拟合"sin 曲线 + 噪声"回归

下面这个小例子把整篇文章打通：数据 → 模型 → 损失 → 优化 → 评估，并在注释里标出每一步对应的概念。

```python
import torch
import torch.nn as nn

torch.manual_seed(42)

# ① 数据：在 sin 曲线上采样并加噪声（回归任务，用 MSE）
x = torch.linspace(-6, 6, 200).unsqueeze(1)          # shape: [200, 1]
y = torch.sin(x) + 0.15 * torch.randn_like(x)         # 真实值 = sin + 噪声

# ② 模型：一个 MLP —— 隐藏层(用 tanh 激活) + 输出层(线性)
model = nn.Sequential(
    nn.Linear(1, 32),       # 输入 1 维 -> 隐藏 32 维，等价于 y=Wx+b
    nn.Tanh(),
    nn.Linear(32, 32),
    nn.Tanh(),
    nn.Linear(32, 1)        # 输出 1 维 = 回归值
)

# ③ 损失（回归用 MSE）+ ④ 优化器（用 Adam）
loss_fn = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# ⑤ 标准训练循环
for epoch in range(2000):
    y_hat = model(x)                # 前向传播
    loss = loss_fn(y_hat, y)        # 计算损失
    optimizer.zero_grad()           # 清空旧梯度（关键！）
    loss.backward()                 # 自动求导：反向传播 + 链式法则
    optimizer.step()                # 参数更新：w ← w - lr * ∂L/∂w

    if (epoch + 1) % 400 == 0:
        print(f"epoch {epoch+1:4d}  loss = {loss.item():.6f}")

# 评估：看模型学的 sin 是否贴合理想曲线（loss 已降到很小即说明学会）
with torch.no_grad():               # 推理模式：不再构建计算图
    pred = model(x)
    print("训练/预测完成，MSE =", ((pred - y) ** 2).mean().item())
```

如果想改成"简单分类"，把最后一层输出改成类别数、`loss_fn` 换成 `nn.CrossEntropyLoss()`、真实标签换成长整型（`torch.long`）即可，损失会自动把 logits 转概率再算交叉熵——这也就是下一站要学的"下一个 token 预测"的单步形态。

## 六、常见坑

1. **忘记 `zero_grad()`**：梯度会跨批次累积，参数更新方向被历史梯度污染，训练发散。
2. **分类用了 MSE**：表现为训练奇慢、loss 震荡，因为梯度饱和。分类请直接用交叉熵。
3. **用 sigmoid 做深层隐藏层**：多层的 sigmoid 相乘把梯度逐层缩到接近 0，出现梯度消失，模型"学不动"。隐藏层换 ReLU 系即可。
4. **ReLU 神经元死亡**：学习率太大让权重更新成负数区间，从此梯度恒 0。对策：调小学习率、用 leaky ReLU、或用 Adam 类优化器。
5. **loss 不降就怀疑模型**：先检查数据是否归一化/类型是否正确（label 必须是 long 而不是 float）、学习率是否过小/过大。学习率试探可用 1e-3 附近做基准。
6. **BN/Dropout 模式错乱**：训练用 `model.train()`，推理用 `model.eval()`，否则推理结果会是随机的。
7. **过拟合只看训练集**：必须切出验证集，用验证指标决定是否早停，否则模型的泛化能力无从谈起。

## 七、小结与衔接

一句话总结：**深度学习 = 多层非线性变换（MLP）+ 一个合理损失（MSE/交叉熵）+ 反向传播链式法则求梯度 + 优化器沿着负梯度更新参数 + 各种正则化防止过拟合**，剩下的全是工程细节。刚才的 PyTorch 例子已经出现了 `nn.Linear`、tensor、`backward()`、`optimizer.step()` 这些核心武器。
