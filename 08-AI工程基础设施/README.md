## 推荐学习顺序

1. **先了解"运行时"长什么样**：`01-K8S与AI` — GPU 怎么被调度，HAMi 怎么实现 GPU 共享
2. **再看"流量入口"**：`03-LLM网关与代理` — LLM API 怎么做路由、负载均衡、容灾
3. **然后是"服务本身"**：`04-模型推理服务` — 模型怎么高效地跑起来
4. **最后是"监控闭环"**：`02-可观测性` — 跑起来之后怎么知道它好不好、贵不贵
