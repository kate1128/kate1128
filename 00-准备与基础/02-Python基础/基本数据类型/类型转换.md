# Python 的数值精度处理
## 浮点数精度
+ **Python** 默认使用 **双精度浮点数**（等价于 C 的 `**double**` 或 Go 的 `**float64**`）

```python
a = 3.141592653589793
print(a.hex())  # 输出十六进制表示，验证精度
```

+ **Go** 需显式指定精度：

```go
var a float32 = 3.14
var b float64 = 3.141592653589793
```

## 整数类型
+ **Python** 的 `**int**` 类型自动支持 **任意精度**：

```python
big_num = 123456789012345678901234567890
```

+ **Go** 需明确指定整数类型：

```python
var a int32 = 42
var b int64 = 9223372036854775807
```

#  变量类型声明机制
## 动态类型特性
```python
x = 42          # int
x = "hello"     # 动态变为 str
x = [1, 2, 3]   # 动态变为 list
```

## 类型提示（可选）
```python
def add(a: int, b: int) -> int:
    return a + b

value: list[str] = ["a", "b"]
```

**与 Go 对比**：

| **特性** | **Python** | **Go** |
| :--- | :--- | :--- |
| 变量声明 | **无需类型** | 必须声明类型 |
| 类型检查 | 运行时动态检查 | 编译期静态检查 |
| 类型注解 | 可选（Type Hints） | 强制类型声明 |

# 类型系统深度对比
## 类型转换示例
**Python**：

直接就是`类型（变量）`？

```python
num_str = "42"
num = int(num_str)       # 显式转换
pi = float("3.14")
flag = bool("")          # False
```

**Go**：

```go
numStr := "42"
num, _ := strconv.Atoi(numStr)  // 必须显式转换
pi, _ := strconv.ParseFloat("3.14", 64)
flag := len("") == 0           // false
```

# 最佳实践指南
## 数值精度控制
都是导包做的？？

+ 使用 `**decimal**` 模块处理金融计算：

```python
from decimal import Decimal
price = Decimal('9.99')  # 避免浮点误差
```

+ 使用 `**numpy**` 获得类似 Go 的类型控制：

```python
import numpy as np
arr = np.array([1,2,3], dtype=np.float32)
```

## 类型提示规范
这是什么Union？？

```python
from typing import Union

def process(data: Union[str, bytes]) -> int:
    if isinstance(data, str):
        return len(data.encode('utf-8'))
    return len(data)
```

# 总结与选择建议
| **场景** | **Python 优势** | **Go 优势** |
| :--- | :--- | :--- |
| 快速原型开发 | 动态类型加速开发 | 编译速度极快 |
| 数值计算 | numpy 高性能计算库 | 原生高性能数值运算 |
