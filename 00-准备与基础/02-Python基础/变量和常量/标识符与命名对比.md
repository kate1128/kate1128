# Python 标识符核心规则
变量是标识符的例子。标识符是用来标识某样东西的名字。在命名标识符的时候，要遵循这些规则：

+ 标识符的**第一个字符**必须是字母表中的**字母（大写或小写）**或者一个**下划线 **（‘`_`’）。
+ 标识符名称的**其他部分**可以由**字母（大写或小写）**、**下划线**（‘`_`’）或**数字（0-9）**组成。
+ 标识符名称是对**大小写敏感**的。例如， `myname` 和 `myName` 不是一个标识符。注意前者中的小写 n 和后者中的大写 N 。
+ **有效标识符**名称的例子有 `i` 、` __my_name` 、 `name_23` 和 `a1b2_c3` 。
+ **无效标识符**名称的例子有 `2things` 、 `this is spaced out `和 `my-name` 。

## 基本命名规范
+ **有效字符**：字母（a-zA-Z）、数字（0-9）、下划线 `_`
+ **首字符限制**：不能以数字开头
+ **长度限制**：理论上无限制
+ **大小写敏感**：`myVar` 和 `myvar` 是不同的标识符
+ **保留字限制**：不能使用 Python 的 35 个关键字

**有效示例**：

```python
username = "Alice"
_user_count = 10
MAX_LIMIT = 100  # 常量约定
def calculate_area():
    pass
class MyClass:
    def __init__(self):
        self._internal_data = []
```

**无效示例**：

```python
3d_model = ...   # 数字开头
class = ...       # 使用关键字
my-var = ...      # 包含连字符
```

## 特殊命名约定
| **模式** | **含义** | **示例** |
| :--- | :--- | :--- |
| 单下划线前缀 `_var` | **约定为内部使用（非强制）** | `_internal_data` |
| 双下划线前缀 `__var` | 名称修饰（Name Mangling） | `__private_field` |
| 双下划线后缀 `var__` | 避免与 Python 特殊方法冲突 | `init__`（不推荐） |
| 全大写 `VAR` | 约定为常量（实际仍可变） | `MAX_CONNECTIONS` |

# Go 标识符核心规则
## 基本命名规范
+ **有效字符**：Unicode 字母、数字、下划线 `_`
+ **首字符限制**：必须为字母或下划线
+ **长度限制**：理论上无限制
+ **大小写敏感**：`myVar` 和 `MyVar` 不同
+ **保留字限制**：不能使用 Go 的 25 个关键字 + 37 个预定义标识符

**有效示例**：

```go
username := "Bob"
var UserCount int = 10
const MaxLimit = 100
func CalculateArea() {
    //...
}
type MyStruct struct {
    internalData []int
}
```

**无效示例**：

```go
3dModel := ...    // 数字开头
func := ...       // 使用关键字
my-var := ...     // 包含连字符
```

## 特殊命名约定
| **模式** | **含义** | **示例** |
| :--- | :--- | :--- |
| 驼峰命名 `varName` | 标准变量命名法 | `userCount` |
| 首字母大写 `Var` | 导出标识符（包外可见） | `ExportedFunction` |
| 下划线前缀 `_var` | 忽略未使用变量或占位 | `_ = someValue` |
| 全大写 `VAR` | 包级常量（实际不可变） | `MAX_CONNECTIONS` |

# 核心差异对比
## 命名规则差异
| **特性** | **Python** | **Go** |
| :--- | :--- | :--- |
| 有效字符范围 | ASCII + 扩展Unicode（中文可用） | 支持Unicode但推荐ASCII |
| 命名风格 | 小写+下划线（snake_case） | 驼峰命名（camelCase） |
| 可见性控制 | 下划线前缀约定（`_var`） | 首字母大写控制导出（`Var`） |
| 私有实现 | 双下划线前缀名称修饰（`__var`） | 小写开头即包私有 |
| 常量定义 | 全大写约定（实际可变） | 编译期真常量（`const`） |

**eg： 错误处理差异**

异常命名习惯一样的

**Python 异常命名**：

```python
class ValidationError(Exception):
    """自定义异常类型"""
    def __init__(self, message):
        super().__init__(message)

try:
    validate_input(data)
except ValidationError as e:
    print(f"错误：{e}")
```

**Go 错误处理**：

```go
type ValidationError struct {
    Msg string
}

func (e *ValidationError) Error() string {
    return e.Msg
}

func ValidateInput(data interface{}) error {
    if invalid {
        return &ValidationError{Msg: "无效输入"}
    }
    return nil
}

if err := ValidateInput(data); err != nil {
    fmt.Printf("错误：%v", err)
}
```

# 总结
## Python
+ 避免使用 `__double_underscore` 除非需要名称修饰
+ 多用下划线
+ 使用类型提示增强可读性：

```python
from typing import List, Dict

def process(data: List[Dict[str, int]]) -> bool:
    ...
```

## Go
+ 严格遵循导出规则（首字母大写导出）
+ 使用短变量名在局部作用域（如 `i` 表示索引）
+ 接口名推荐 `-er` 后缀：

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}
```

# 命名对方法的影响
python 是有一些语法糖，基本是固定命名的方法，这个得整理下！！

单下划线也是约定内部，不强制，那就是命名对私有公有作用域没什么影响？

## Python 特殊方法
```python
class Vector:
    def __init__(self, x, y):  # 构造方法
        self.x = x
        self.y = y

    def __add__(self, other):  # 运算符重载
        return Vector(self.x + other.x, self.y + other.y)

    @property
    def magnitude(self):       # 属性装饰器
        return (self.x**2 + self.y**2)**0.5
```

## Go 导出控制
```go
// 包 visible 中的导出控制
package visible

var PublicVar int     // 导出变量（首字母大写）
const PrivateConst = 42 // 包内私有（小写开头）

type ExportedStruct struct {  // 导出结构体
    PublicField  int    // 导出字段
    privateField string // 私有字段
}

func (s *ExportedStruct) PublicMethod() {}  // 导出方法
func (s *ExportedStruct) privateMethod() {} // 私有方法
```
