> + python 给变量都是直接给`等号（=）`，有变量直接定义，不用初始化类型
> + 修改全局变量的话要在 def 里在变量前加`global`
>

# 总结对比表
| **特性** | **Python** | **Go** |
| :--- | :--- | :--- |
| 变量类型 | **动态类型** | 静态类型 |
| 常量定义 | 约定式伪常量 | 编译期真常量 |
| 参数传递灵活性 | 高（默认参数、关键字参数等） | 低（需严格匹配类型） |
| 多返回值 | 自然支持 | 需明确声明 |
| 错误处理 | 异常机制 | 显式错误返回值 |
| 内存管理 | 自动垃圾回收 | 自动GC + 手动控制机会 |
| 并发安全 | GIL 限制 | Goroutine 安全模型 |

**开发建议**：

+ **Python**：适合快速原型开发，利用动态类型优势
+ **Go**：适合需要严格类型检查和高并发的系统级开发
+ **参数设计**：
    - Python 可多用可变参数和关键字参数增加灵活性
    - Go 推荐使用结构体封装复杂参数
+ **常量使用**：
    - Python 严格遵循全大写约定
    - Go 利用 const 确保真正不可变

```python
# 动态类型，无需声明类型
```

```go
// 静态类型，必须明确类型
```

# 函数参数处理
## 参数传递基础
Python 灵活传参：

```python
def process(data, times=1):  # 默认参数
    return data * times

process("Hi", 3)       # 位置参数
process(times=2, data=5)  # 关键字参数
```

Go 严格传参：

```go
func Process(data interface{}, times int) interface{} {
    // 需手动处理类型
    switch v := data.(type) {
        case string:
        return strings.Repeat(v, times)
        case int:
        return v * times
        default:
        return nil
    }
}

Process("Hi", 3)       // 只能位置传参
```

## 可变参数
Python：

```python
def sum_all(*args):
    return sum(args)

print(sum_all(1, 2, 3))  # 6 // 任意类型
```

Go：

```go
func SumAll(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

SumAll(1, 2, 3)  // 必须同类型
```

**关键差异**：

| **特性** | **Python** | **Go** |
| :--- | :--- | :--- |
| 默认参数 | 支持 | 不支持 |
| 关键字参数 | 支持 | 不支持 |
| 可变参数类型 | **任意类型** | 必须统一类型 |
| 参数校验 | 运行时动态检查 | 编译期静态检查 |

```python
def split_name(full_name):
    names = full_name.split()
    return names[0], names[1] if len(names)>1 else ""

first, last = split_name("Alice Smith")
```

**Go**：

```go
func SplitName(fullName string) (string, string) {
    names := strings.Split(fullName, " ")
    if len(names) > 1 {
        return names[0], names[1]
    }
    return names[0], ""

firstName, lastName := SplitName("Alice Smith")
```

## 错误处理
**Python**：

```python
def divide(a, b):
    try:
        return a / b, None
    except ZeroDivisionError as e:
        return None, str(e)

result, error = divide(10, 0)
```

**Go**：

```go
func Divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("division by zero")
    }
    return a / b, nil
}

result, err := Divide(10, 0)
```

**关键差异**：

| **特性** | **Python** | **Go** |
| :--- | :--- | :--- |
| 返回值数量 | **不限** | 不限但需明确声明 |
| 错误处理 | 异常机制 | 显式错误返回值 |
| 返回值类型 | **动态类型** | 必须明确类型 |

# 常量定义
一个字面意义上的常量的例子是如同 `5` 、 `1.23 `、` 9.25e-3 `这样的数，或者如同 `‘This is a string’ `、 `"It’sa string!" `这样的字符串。

它们被称作字面意义上的，因为它们具备字面的意义 ，你按照它们的字面意义使用它们的值。

数 `2` 总是代表它自己，而不会是别的什么东西 ，它是一个常量，因为不能改变它的值。因此，所有这些都被称为字面意义上的常量。

## 基本定义
**Python**（约定常量）：

```python
MAX_CONNECTIONS = 100   # 全大写约定，实际仍可变
PI = 3.1415926

# 尝试修改不会报错
MAX_CONNECTIONS = 200   # 允许但不符合规范
```

**Go**（真正常量）：

```go
const (
    MaxConnections = 100
    Pi = 3.1415926
)

// 以下代码会编译报错
// MaxConnections = 200
```

## 枚举实现
**Python**：继承这个类Enum

```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
    BLUE = 3

print(Color.RED.value)  # 1
```

**Go**：

```go
type Color int

const (
    Red Color = iota + 1
    Green
    Blue
)

fmt.Println(Red)  // 1
```

**关键差异**：

| **特性** | **Python** | **Go** |
| :--- | :--- | :--- |
| 常量不可变性 | 仅约定，实际可修改 | 编译期强制不可修改 |
| 枚举支持 | 通过 Enum 类实现 | 通过 iota 实现 |
| 类型要求 | 无类型限制 | 必须明确基础类型 |

# 作用域对比
## 全局变量
**Python**：

```python
count = 0

def increment():
    global count
    count += 1

increment()
print(count)  # 1
```

**Go**：

```go
var count int = 0

func Increment() {
    // 直接修改会编译错误
    // count += 1
}

// 正确方式
func Increment() {
    globalMutex.Lock()
    defer globalMutex.Unlock()
    count++
}
```

## 闭包
**Python**：

```python
def counter():
    n = 0
    def inc():
        nonlocal n
        n += 1
        return n
    return inc

c = counter()
print(c(), c())  # 1 2
```

**Go**：

```go
func Counter() func() int {
    n := 0
    return func() int {
        n++
        return n
    }
}

c := Counter()
fmt.Println(c(), c())  // 1 2
```

**关键差异**：

| **特性** | **Python** | **Go** |
| :--- | :--- | :--- |
| 全局变量修改 | 需要 `global`声明 | 包级变量需谨慎处理 |
| 闭包实现 | 自然支持 | 自然支持 |
| 线程安全 | GIL 保护基本操作 | 需手动加锁 |
