# `*args` 与 `**kwargs` 的作用
## 参数解包语法
为啥它就知道 args 是 2，3 了？？？

```python
def example(a, *args, **kwargs):
    print("固定参数:", a)
    print("位置参数:", args)  # 元组形式
    print("关键字参数:", kwargs)  # 字典形式

example(1, 2, 3, name="Alice", age=30)
```

**输出**：

```python
固定参数: 1
位置参数: (2, 3)
关键字参数: {'name': 'Alice', 'age': 30}
```

## 在 `__new__` 中的应用
```python
class CustomClass:
    def __new__(cls, *args, **kwargs):
        print("创建实例，参数:", args, kwargs)
        return super().__new__(cls)  # 调用父类的 __new__

    def __init__(self, name, value):
        self.name = name
        self.value = value

obj = CustomClass("demo", 42, extra=5)
```

**输出**：

```python
创建实例，参数: ('demo', 42) {'extra': 5}
```

# `__str__` 方法的作用
## 未定义 `__str__` 的情况
不定义的话输出的是地址？？

```python
class BasicList:
    def __init__(self, data):
        self.data = data

lst = BasicList([1,2,3])
print(lst)  # 输出: <__main__.BasicList object at 0x...>
```

## 定义 `__str__` 后
```python
class PrettyList:
    def __init__(self, data):
        self.data = data

    def __str__(self):
        return f"优雅的列表: {self.data}"

lst = PrettyList([1,2,3])
print(lst)  # 输出: 优雅的列表: [1, 2, 3]
```

## 对比 `__repr__`
和`__str__` 有啥区别？？

```python
class DebugList:
    def __repr__(self):
        return "开发者用的表示"

dl = DebugList()
print(dl)  # 输出: 开发者用的表示（当 __str__ 未定义时，自动用 __repr__）
```

#  不可变类型详解
## 不可变对象定义
不可变就是不允许修改，元素不可以修改！！go 里有对应的结构吗？

```python
# 元组（不可变）
t = (1, 2, 3)
t[0] = 5  # 报错: TypeError

# 列表（可变）
lst = [1, 2, 3]
lst[0] = 5  # 允许修改
```

## 常见不可变类型
| **类型** | **示例** | **特性** |
| :--- | :--- | :--- |
| 元组 | `(1, "a")` | 元素不可变 |
| 字符串 | `"hello"` | 字符不可变 |
| 整数 | `42` | 值不可变 |
| 浮点数 | `3.14` | 值不可变 |
| 冻结集合 | `frozenset({1,2})` | 集合元素不可变 |

## 元组特殊用法
```python
# 单元素元组需加逗号
single = (42,)  # 正确
not_single = (42)  # 实际是整数

# 解包操作
a, b, c = (1, 2, 3)
```

# 与 Go 的对比
## 参数处理
**Python**：

```python
def variadic(*args):
    print(args)
```

**Go**：

```go
// Go 的可变参数
func variadic(args ...int) {
    fmt.Println(args)
}
```

## 不可变设计
**Python**：

```python
# 语言原生支持不可变类型
hashtable = { (1,2): "value" }  # 元组作为键合法
```

**Go**：

```go
// Go 中数组是值类型（类似不可变）
arr := [3]int{1,2,3}
arrCopy := arr  // 深拷贝

// 但无原生不可变集合类型
```

# 最佳实践建议
## 参数处理原则
+ 使用 `*args` 收集不确定数量的位置参数
+ 使用 `**kwargs` 收集关键字参数
+ 在继承场景中保持参数传递灵活性

## 字符串表示规范
+ 为重要类实现 `__str__` 提升可读性
+ 始终实现 `__repr__` 用于调试
+ 遵循惯例：`__repr__` 的输出应能用于 `eval()` 重建对象

## 不可变类型使用场景
+ 字典的键
+ 多线程共享数据
+ 函数默认参数
+ 需要哈希化的场景
