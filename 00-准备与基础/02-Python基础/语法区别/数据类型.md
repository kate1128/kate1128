# 类的继承机制解析
## Python 类继承原理
```python
class BaseClass:
    def __new__(cls):
        print("Base __new__")
        return super().__new__(cls)  # 实际调用 object.__new__

class CustomClass(BaseClass):
    def __new__(cls):
        print("Custom __new__")
        return super().__new__()  # 调用父类 BaseClass.__new__
```

**关键点**：

+ 所有类默认继承 `object` 类
+ `super()` 根据 MRO (方法解析顺序) 动态确定父类
+ `__new__` 是实例化入口方法，必须返回实例

## Go 的 “继承” 实现
```go
type Animal struct {
    Name string
}

func (a Animal) Speak() {
    fmt.Println("Animal sound")
}

type Dog struct {
    Animal  // 结构体嵌入
}

func (d Dog) Speak() {
    d.Animal.Speak()
    fmt.Println("Woof!")
}
```

# `super()` 方法深度解析
## 单继承场景
```python
class Parent:
    def __init__(self):
        print("Parent init")

class Child(Parent):
    def __init__(self):
        super().__init__()  # 明确调用父类初始化
        print("Child init")
```

## 多继承场景 (MRO)
```python
class A:
    def method(self):
        print("A")

class B(A):
    def method(self):
        print("B")
        super().method()

class C(A):
    def method(self):
        print("C")
        super().method()

class D(B, C):
    def method(self):
        print("D")
        super().method()

d = D()
d.method()
```

**输出顺序**：

```python
D → B → C → A
```

## 无显式父类时的 super 行为

class SimpleClass:

# 开发实践建议
## 选择容器的标准
+ **Python**：
    - 快速开发：优先用 list/dict
    - 性能敏感：考虑 array 模块或 numpy
    - 不可变需求：使用 tuple/frozenset
+ **Go**：
    - 确定长度：用数组 `[3]int{1,2,3}`
    - 动态集合：用切片 `[]int{1,2,3}`
    - 快速查找：用 map `map[string]int`

## 类继承最佳实践
+ **Python**：
    - 优先使用组合而非多重继承，什么是组合？
    - 使用 `super()` 保持继承链完整
    - 避免在 `__new__` 中做复杂操作
+ **Go**：
    - 通过接口实现多态
    - 使用结构体嵌入实现代码复用
    - 避免深层次的嵌套结构

# 总结与学习建议
## 核心差异总结
+ **Python**：动态类型 + 鸭子类型 + 灵活继承
+ **Go**：静态类型 + 接口抽象 + 组合优先

## 学习路线建议
+ **Python 重点**：
    - 掌握魔术方法 (`__str__`, `__getitem__` 等)
    - **理解元类与类工厂模式**
    - **熟练使用生成器与装饰器**
+ **Go 重点**：
    - 深入理解接口与空接口
    - 掌握并发模型 (goroutine + channel)
    - 学习高效内存管理技巧

两种语言各有千秋，Python 适合快速原型开发和数据科学，Go 更适合构建高性能分布式系统。建议根据项目需求灵活选择，掌握两者可显著提升全栈开发能力。
