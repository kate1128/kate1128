以下是 Python 与 Go 数据结构的详细对比说明，包含 Python 数据结构的详细解释、常见用法以及与 Go 的对应关系：

# Python 核心数据结构详解
## 列表 (List)
**描述**：

+ 有序、**可变**的元素集合
+ 允许重复元素
+ **支持混合数据类型（元素可以是任意类型）**

**常见操作**：

```python
# 创建
nums = [1, 2, 3, "a", True]  # 混合类型
empty_list = []

# 增删改查
nums.append(4)        # 末尾添加元素 → [1,2,3,'a',True,4]
nums.insert(1, 1.5)   # 插入 → [1,1.5,2,3,'a',True,4]
nums[0] = 100         # 修改 → [100,1.5,2,3,'a',True,4]
del nums[3]           # 删除索引3 → [100,1.5,2,'a',True,4]

# 切片操作
print(nums[1:3])      # 输出 [1.5, 2]
print(nums[::-1])     # 逆序 → [4, True, 'a', 2, 1.5, 100]
```

**Go 对应结构**：

+ **切片 (Slice)**：**功能类似但元素类型必须一致**

```go
// 创建
nums := []interface{}{1, 2, 3, "a", true} // 需用空接口实现混合类型
emptySlice := make([]int, 0)

// 增删
nums = append(nums, 4)                     // 追加
nums = append(nums[:3], nums[4:]...)       // 删除索引3
```

## 元组 (Tuple)
**描述**：

+ 有序、**不可变**的元素集合
+ 常用于存储**不可修改**的数据（如坐标、配置项）

**常见操作**：

```python
# 创建
point = (10, 20)
mixed = ("text", 3.14, [1,2,3])

# 访问元素
print(point[0])       # 输出 10

# 不可变性（会报错）
# point[0] = 100      # TypeError: 'tuple'不支持修改
```

**Go 对应结构**：

+ **数组 (Array)**：长度固定，但元素可修改

```go
// 创建
point := [2]int{10, 20}
var mixed [3]interface{} = [3]interface{}{"text", 3.14, []int{1,2,3}}

// 修改元素
point[0] = 100  // 允许修改
```

## 字典 (Dict)
**描述**：

+ 键值对集合（键必须可哈希，如字符串/数字/元组）
+ 无序（Python 3.7+ 保留插入顺序）
+ 允许动态增删
+ 看起来类型不是固定的？

**常见操作**：

```python
# 创建
user = {"name": "Alice", "age": 30}
empty_dict = {}

# 增删改查
user["email"] = "alice@example.com"  # 添加
del user["age"]                      # 删除
print(user.get("name", "未知"))       # 输出 Alice

# 遍历
for key, value in user.items():
    print(f"{key}: {value}")
```

**Go 对应结构**：

+ **映射 (Map)**：键类型需一致，值类型需一致

```go
// 创建
user := map[string]interface{}{
    "name": "Alice",
    "age":  30,
}

// 增删
user["email"] = "alice@example.com"
delete(user, "age")

// 遍历
for key, value := range user {
    fmt.Printf("%s: %v\n", key, value)
}
```

## 集合 (Set)
**描述**：

+ 无序、**不重复元素**的集合
+ 支持集合运算（交集、并集等）

**常见操作**：

```python
# 创建
s1 = {1, 2, 3}
s2 = set([3, 4, 5])

# 集合运算
print(s1 | s2)    # 并集 → {1,2,3,4,5}
print(s1 & s2)    # 交集 → {3}

# 去重应用
words = ["apple", "banana", "apple"]
unique = set(words)  # {"apple", "banana"}
```

**Go 对应结构**：

+ **map[T]struct{}**：通过映射模拟集合

```go
// 创建
s1 := map[int]struct{}{1: {}, 2: {}, 3: {}}
s2 := map[int]struct{}{3: {}, 4: {}, 5: {}}

// 并集实现
union := make(map[int]struct{})
for k := range s1 { union[k] = struct{}{} }
for k := range s2 { union[k] = struct{}{} }
```

# Python 其他重要数据结构
## 字符串 (String)
**描述**：

+ 不可变的字符序列
+ 支持丰富的字符串操作

**常见操作**：

```python
text = "Hello, 世界!"

# 切片与拼接
print(text[7:])        # 输出 "世界!"
new_text = text + " Welcome"  # 拼接

# 格式化
name = "Bob"
print(f"Hello, {name}!")  # f-string → Hello, Bob!
```

**Go 对应结构**：

+ **string**：不可变字节序列

```go
text := "Hello, 世界!"
part := text[7:]              // 切片
newText := text + " Welcome" // 拼接
fmt.Printf("Hello, %s!", name) // 格式化
```

## 队列 (Queue)
**Python 实现**：

```python
from collections import deque

queue = deque()
queue.append(1)     # 入队
queue.append(2)
item = queue.popleft()  # 出队 → 1
```

**Go 对应结构**：

+ **Slice 模拟队列** 或 **Channel**

```go
// 切片实现
queue := []int{}
queue = append(queue, 1)          // 入队
item := queue[0]
queue = queue[1:]                 // 出队

// 通道实现（并发安全）
ch := make(chan int, 10)
ch <- 1  // 入队
val := <-ch  // 出队
```

## 堆 (Heap)
**Python 实现**：

```python
import heapq

nums = [3, 1, 4]
heapq.heapify(nums)  # 转换为堆
heapq.heappush(nums, 2)
print(heapq.heappop(nums))  # 弹出最小值 → 1
```

**Go 对应结构**：

+ **container/heap 包**

```go
import "container/heap"

// 定义堆类型
type IntHeap []int
func (h IntHeap) Len() int { ... } // 实现接口

h := &IntHeap{3, 1, 4}
heap.Init(h)
heap.Push(h, 2)
fmt.Println(heap.Pop(h)) // 输出 1
```

# 对比总结表
| **数据结构** | **Python 实现** | **Go 对应实现** | **核心差异** |
| :--- | :--- | :--- | :--- |
| **动态数组** | `list`
（混合类型） | `slice`
（元素类型一致） | Python 更灵活，Go 类型安全 |
| **键值对** | `dict`
（任意可哈希键） | `map`
（键类型需一致） | Go 需初始化，Python 可动态创建 |
| **不可变序列** | `tuple` | `array`
（长度固定，元素可修改） | Python 的元组完全不可变，Go 数组元素可修改 |
| **集合** | `set`
（内置操作符） | `map[T]struct{}`
（手动实现运算） | Python 提供集合运算符，Go 需手动实现 |
| **字符串** | `str`
（支持 Unicode） | `string`
（UTF-8 编码） | 两者均不可变，但 Go 字符串本质是字节切片 |
| **队列** | `collections.deque`
（双向队列） | `slice`
 或 `channel`
（并发场景） | Go 的 channel 是并发安全的 |
| **堆** | `heapq`
 模块 | `container/heap`
 包 | 两者均需手动实现堆接口 |

# 设计哲学差异
| **维度** | **Python 设计思路** | **Go 设计思路** |
| :--- | :--- | :--- |
| **类型灵活性** | 动态类型，允许混合类型容器 | 静态类型，容器元素类型必须一致 |
| **内存管理** | 自动垃圾回收，开发者无需关心 | 自动 GC + 栈分配优化 |
| **并发支持** | 通过 `asyncio`
 协程处理 I/O 密集型任务 | 原生支持 `goroutine`
 + `channel` |
| **扩展性** | 通过 C 扩展提升性能（如 NumPy） | 直接编译为机器码，性能更高 |

# 学习建议
1. **从 Go 迁移到 Python**：
+ 注意列表（`list`）与切片（`slice`）的混合类型特性
+ 使用字典（`dict`）时无需担心类型约束
+ 优先使用 `collections.deque` 实现队列而非普通列表

2. **常用技巧**：

```python
# 快速去重
unique = list(set([1,2,2,3]))  # → [1,2,3]

# 字典推导式
squares = {x: x**2 for x in range(5)}

# 合并字典（Python 3.9+）
dict1 = {"a": 1}
dict2 = {"b": 2}
merged = dict1 | dict2  # → {'a':1, 'b':2}
```

3. **性能敏感场景**：
+ 优先使用元组（`tuple`）替代列表（`list`）存储不变数据
+ 使用 `sys.intern()` 优化大量重复字符串的内存占用
