# Python 继承机制详解
## 继承实现方式
```python
class Animal:
    def speak(self):
        print("Animal sound")

class Dog(Animal):  # 括号指定父类
    def speak(self):
        super().speak()  # 调用父类方法
        print("Woof!")

d = Dog()
d.speak()
```

**输出结果**：

```plain
Animal sound
Woof!
```

## Go 的 “继承” 实现
```go
type Animal struct{}

func (a Animal) Speak() {
    fmt.Println("Animal sound")
}

type Dog struct {
    Animal  // 嵌入结构体实现组合
}

func (d Dog) Speak() {
    d.Animal.Speak()  // 调用嵌入结构体的方法
    fmt.Println("Woof!")
}

func main() {
    d := Dog{}
    d.Speak()
}
```

**输出结果**：

```plain
Animal sound
Woof!
```

**关键差异**：

+ Python 显式继承父类
+ Go 通过结构体嵌入实现组合式继承
+ 两者都支持方法重写

# with 语句深入解析
## Python 上下文管理器
```python
# 自定义上下文管理器
class DatabaseConnection:
    def __enter__(self):
        print("Connecting to DB")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        print("Closing connection")

    def query(self):
        print("Executing query")

# 使用示例
with DatabaseConnection() as conn:
    conn.query()
    # 自动调用 __exit__
```

## Go 的资源管理
```go
type DatabaseConnection struct{}

func (d *DatabaseConnection) Connect() {
    fmt.Println("Connecting to DB")
}

func (d *DatabaseConnection) Close() {
    fmt.Println("Closing connection")
}

func (d *DatabaseConnection) Query() {
    fmt.Println("Executing query")
}

func main() {
    db := &DatabaseConnection{}
    db.Connect()
    defer db.Close()  // 延迟执行

    db.Query()
    // 函数结束时自动调用 Close()
}
```

**核心差异**：

| **特性** | **Python**** **`**with**` | **Go**** **`**defer**` |
| :--- | :--- | :--- |
| 资源获取 | `__enter__`
 返回资源 | 需显式调用初始化方法 |
| 异常/错误处理 | 通过 `__exit__`
 参数处理 | 需手动检查错误 |
| 作用域 | 限定在代码块内 | 函数级作用域 |
| 实现复杂度 | 需要实现协议方法 | 直接调用+defer 即可 |

**Python**：

```python
# 列表推导式
squares = [x**2 for x in range(10) if x%2 ==0]

# 切片操作
nums = [1,2,3,4,5]
```

```go
var squares []int

        squares = append(squares, x*x)
    }

nums := []int{1,2,3,4,5}
```

## 接口/协议
**Python 鸭子类型**：

```python
class Writer:
    def write(self, data):
        pass

def save_data(w: Writer):
    w.write("data")

# 任何实现 write() 的对象都可用
save_data(open("file.txt", "w"))
save_data(StringIO())
```

**Go 接口**：

```go
type Writer interface {
    Write([]byte) (int, error)
}

func saveData(w Writer) {
    w.Write([]byte("data"))
}

// 任何实现 Write 方法的类型都满足接口
saveData(os.Stdout)
saveData(&bytes.Buffer{})
```

## 并发处理
**Python 线程**：

```python
import threading

def worker(num):
    print(f"Worker {num}")

threads = []
for i in range(3):
    t = threading.Thread(target=worker, args=(i,))
    threads.append(t)
    t.start()

for t in threads:
    t.join()
```

**Go 协程**：

```go
func worker(num int, wg *sync.WaitGroup) {
    defer wg.Done()
    fmt.Printf("Worker %d\n", num)
}

func main() {
    var wg sync.WaitGroup
    for i := 0; i < 3; i++ {
        wg.Add(1)
        go worker(i, &wg)
    }
    wg.Wait()
}
```

# 核心设计哲学对比
| **设计维度** | **Python 哲学** | **Go 哲学** |
| :--- | :--- | :--- |
| 类型系统 | “鸭子类型” 动态检查 | 严格静态类型 |
| 错误处理 | 异常机制 (EAFP) | 显式错误返回值 |
| 并发模型 | 线程 + GIL 限制 | 协程 + 无锁通信 |
| 代码风格 | 灵活多范式 | 强制统一格式 |
| 性能目标 | 开发效率优先 | 运行效率优先 |
| 元编程 | 强大的反射和元类 | 有限反射支持 |
| 依赖管理 | 后期引入类型提示 | 原生强类型支持 |

```python

sum_sq = reduce(lambda x,y: x+y, map(lambda x: x**2, range(10)))
```

**Go**：

```go
    sum := 0
    for x := 0; x < 10; x++ {
```
