以下是 Python 与 Go 运算符的详细对比及示例说明：

#  算术运算符
| **运算符** | **Python 示例** | **Go 示例** | **核心差异** |
| :--- | :--- | :--- | :--- |
| `+` | `3 + 2 → 5` | `3 + 2 → 5` | 相同 |
| `-` | `5 - 3 → 2` | `5 - 3 → 2` | 相同 |
| `*` | `2 * 3 → 6` | `2 * 3 → 6` | 相同 |
| `/` | `7 / 2 → 3.5` | `7 / 2 → 3` (整数除法) | Go 整数除法结果向下取整，需用 `float`
 类型：`7.0 / 2 → 3.5` |
| `//` | `7 // 2 → 3` (整除) | 无，用 `/`替代 | Go 无专门整除运算符 |
| `%` | `7 % 2 → 1` | `7 % 2 → 1` | 相同 |
| `**` | `2 ** 3 → 8` (幂运算) | 无，用 `math.Pow(2,3)` | Go 需调用数学函数 |

**代码示例**：

```python
# Python
print(7 / 2)   # 3.5
print(7 // 2)  # 3
print(2 ** 3)  # 8
```

```go
// Go
fmt.Println(7 / 2)          // 3
fmt.Println(7.0 / 2)        // 3.5
fmt.Println(math.Pow(2,3))  // 8
```

# 比较运算符
| **运算符** | **Python 示例** | **Go 示例** | **核心差异** |
| :--- | :--- | :--- | :--- |
| `==` | `3 == 3 → True` | `3 == 3 → true` | 相同 |
| `!=` | `3 != 5 → True` | `3 != 5 → true` | 相同 |
| `>` | `5 > 3 → True` | `5 > 3 → true` | 相同 |
| `<` | `3 < 5 → True` | `3 < 5 → true` | 相同 |
| `>=` | `5 >= 5 → True` | `5 >= 5 → true` | 相同 |
| `<=` | `3 <= 5 → True` | `3 <= 5 → true` | 相同 |

**链式比较差异**：

```python
# Python 支持链式比较
if 1 < x < 5: ...
```

```go
// Go 需拆分比较
if x > 1 && x < 5 { ... }
```

# 逻辑运算符
| **运算符** | **Python 示例** | **Go 示例** | **核心差异** |
| :--- | :--- | :--- | :--- |
| `and` | `x > 0 and y < 10` | `x > 0 && y < 10` | Python 用单词，Go 用符号 |
| `or` | `x == 0 or y == 0` | `x == 0 || y == 0` | 同上 |
| `not` | `not x` | `!x` | Python 用单词，Go 用符号 |

**代码示例**：

```python
# Python
if x > 0 and y < 10: ...
```

```go
// Go
if x > 0 && y < 10 { ... }
```

# 位运算符
| **运算符** | **Python 示例** | **Go 示例** | **核心差异** |
| :--- | :--- | :--- | :--- |
| `&` | `0b1010 & 0b1100 → 0b1000` | `0b1010 & 0b1100 → 8` | 相同 |
| `\|` | `0b1010 | 0b1100 → 0b1110` | `0b1010 | 0b1100 → 14` | 相同 |
| `^` | `0b1010 ^ 0b1100 → 0b0110` | `0b1010 ^ 0b1100 → 6` | 相同 |
| `<<` | `1 << 3 → 8` | `1 << 3 → 8` | 相同 |
| `>>` | `8 >> 2 → 2` | `8 >> 2 → 2` | 相同 |
| `~` | `~0b1010 → -0b1011` | 无，用 `^x` | Go 用 `^x` 实现按位取反 |

**代码示例**：

```python
# Python
print(bin(0b1010 & 0b1100))  # 0b1000
print(~0b1010)               # -11 (二进制补码)
```

```go
// Go
fmt.Printf("%b\n", 0b1010 & 0b1100) // 1000
fmt.Println(^0b1010)                // -11 (对整数取反)
```

# 赋值运算符
| **运算符** | **Python 示例** | **Go 示例** | **核心差异** |
| :--- | :--- | :--- | :--- |
| `=` | `x = 10` | `x := 10`或 `var x = 10` | Go 使用短声明 `:=` 和 `var` 关键字 |
| `+=` | `x += 5` | `x += 5` | 相同 |
| `-=` | `x -= 3` | `x -= 3` | 相同 |
| `*=` | `x *= 2` | `x *= 2` | 相同 |
| `/=` | `x /= 4` | `x /= 4` | Go 整数除法会取整 |
| `%=` | `x %= 3` | `x %= 3` | 相同 |
| `**=` | `x **= 3` | 无，需用 `x = x * x` | Go 无幂运算赋值 |
| `&=` | `x &= 0b1111` | `x &= 0b1111` | 相同 |
| `\|=` | `x |= 0b1010` | `x |= 0b1010` | 相同 |
| `^=` | `x ^= 0b1010` | `x ^= 0b1010` | 相同 |
| `<<=` | `x <<= 2` | `x <<= 2` | 相同 |
| `>>=` | `x >>= 1` | `x >>= 1` | 相同 |

# 特殊运算符
## Python 特有
| **运算符** | **说明** | **示例** | **Go 替代方案** |
| :--- | :--- | :--- | :--- |
| `in` | 成员检测 | `3 in [1,2,3] → True` | 遍历切片或使用 `map` |
| `is` | 对象身份比较 | `x is None` | 指针比较：`ptr == nil` |
| `@` | 矩阵乘法（NumPy） | `A @ B` | 使用库函数（如 `gonum/math`） |

**代码示例**：

```python
# Python
if key in {"a":1, "b":2}:
    print("Exists")

if x is None:
    handle_empty()
```

```go
// Go
m := map[string]int{"a":1, "b":2}
if _, ok := m["a"]; ok {
    fmt.Println("Exists")
}

if ptr == nil {
    handleEmpty()
}
```

## Go 特有
| **运算符** | **说明** | **示例** | **Python 替代方案** |
| :--- | :--- | :--- | :--- |
| `&` | 取地址 | `ptr := &x` | 无直接等价（Python 无指针） |
| `*` | 解引用 | `val := *ptr` | 无直接等价 |
| `<-` | 通道操作 | `ch <- 10`或 `x := <-ch` | 使用 `queue.Queue`等库 |
| `...` | 可变参数/展开切片 | `func sum(nums ...int) {}` | `*args`参数 |

**代码示例**：

```go
// Go
x := 10
ptr := &x     // 取地址
fmt.Println(*ptr) // 解引用

ch := make(chan int)
go func() { ch <- 10 }()
val := <-ch
```

```python
# Python 无直接等价操作
import queue
q = queue.Queue()
q.put(10)
val = q.get()
```

# 运算符优先级对比
## 核心差异
| **优先级** | **Python 典型运算符** | **Go 典型运算符** |
| :--- | :--- | :--- |
| 最高 | `**` | `* / % << >> & &^` |
| 中间 | `* / // %`→ `+ -` | `+ - | ^`→ `== != < <= > >=` |
| 最低 | `and` → `or` | `&&`→ `||` |

**注意事项**：

1. Python 中 `**` 的优先级高于乘除
2. Go 中位运算符优先级高于比较运算符
3. 建议使用括号明确优先级

# 总结表格
| **特性** | **Python** | **Go** |
| :--- | :--- | :--- |
| 除法行为 | `/`返回浮点，`//`整除 | `/`根据操作数类型决定结果 |
| 逻辑运算符 | `and`
 `or`
 `not` | `&&`
 `||`
 `!` |
| 成员检测 | `in`运算符直接支持 | 需手动遍历或使用 `map` |
| 指针操作 | 无 | `&`取地址，`*`解引用 |
| 自增/自减 | 无 `++`/`--`，用 `+=1`/`-=1` | 支持 `x++`和 `x--` |
| 幂运算 | `**`运算符 | 依赖 `math.Pow` 函数 |

理解这些差异可以帮助开发者在跨语言编程时避免常见错误，例如：

+ 在 Go 中处理整数除法时需注意类型转换
+ 迁移 Python 的 `in` 检测逻辑到 Go 时需要重写遍历逻辑
+ 在 Go 中严格使用括号明确复杂表达式优先级
