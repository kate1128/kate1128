# Python 模块与 Go 包的对比
## Python 模块系统
**定义与使用**：

所以 from 是文件名，import 是类名？什么情况下需要导包？

```python
# mymodule.py
def hello():
    print("Hello from module!")

class Calculator:
    def add(self, a, b):
        return a + b

if __name__ == "__main__":
    # 模块自测试代码
    hello()
```

**导入方式**：

```python
import mymodule                  # 整体导入
from mymodule import Calculator  # 选择性导入
import mymodule as mm            # 别名导入

mymodule.hello()
calc = Calculator()
```

## Go 包系统
**定义与使用**：

```go
// mypackage/mypackage.go
package mypackage

import "fmt"

func Hello() {
    fmt.Println("Hello from package!")
}

type Calculator struct{}

func (c Calculator) Add(a, b int) int {
    return a + b
}
```

**导入方式**：

```go
import "mypackage"               // 默认导入
import mpkg "mypackage"          // 别名导入
import . "mypackage"             // 直接访问（不推荐）

func main() {
    mypackage.Hello()
    calc := mypackage.Calculator{}
}
```

**核心差异**：

| **特性** | **Python 模块** | **Go 包** |
| :--- | :--- | :--- |
| 文件组织 | 单文件即模块 | 需目录同名包 |
| 访问控制 | 下划线开头表示私有 (`_internal`) | 首字母大写为公开 |
| 初始化 | `if __name__ == "__main__"` | `init()`函数 |
| 依赖管理 | `requirements.txt`
 + `pip` | `go.mod`
 + `go get` |
