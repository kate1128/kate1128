# 大模型开发（LLM Application Development）

> 以大型语言模型（LLM）为功能核心，通过 Prompt Engineering、数据工程和业务逻辑编排，构建 AI 原生应用的过程。**核心在于用好模型，而非改造模型**。

## 是什么

大模型开发与传统深度学习开发有本质区别：

| 维度 | 传统 DL 开发 | 大模型开发 |
| --- | --- | --- |
| 核心工作 | 训练/微调模型 | 设计 Prompt 和业务逻辑 |
| 模型角色 | 产品本身 | 被调用的"推理引擎" |
| 技术重心 | 算法、框架、GPU | API、工程化、数据流 |
| 迭代方式 | 重新训练 | 改 Prompt / 换检索策略 |

简单来说：**大模型开发是一个工程问题，而不是算法问题**。开发者通过 API 调用模型，用 Prompt Engineering 控制行为，用 RAG 扩展知识，用 Agent 框架编排多步任务。

## 为什么重要

- **门槛降低**：不需要 PhD 也能做出 AI 应用——这是大模型开发的革命性意义
- **技能栈转型**：从"会训练模型"到"会用模型"——Prompt Engineering、RAG、Agent、API 集成、产品设计
- **效率跃进**：一个 Prompt 改动 5 分钟生效 vs 微调一个模型需要数天

## 关键要点

- **核心能力栈**：Prompt Engineering → RAG → Agent/Function Calling → MCP 协议 → 应用工程化
- **模型是工具，不是产品**：大部分 AI 应用不需要自研模型，调用 API 就够了
- **关注点**：数据质量（Garbage in, Garbage out）、成本控制（Token 消耗）、延迟优化（缓存/流式）、安全（注入防御）
- **学习路径**：本知识库的架构就是按照大模型开发的完整链路组织的
