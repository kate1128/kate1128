# 结构化数据（Structured Data）

> 严格按照预定义模型（如二维表）组织的数据，每条记录有相同的字段结构和类型约束。这是传统数据库和 BI 系统处理的主要数据类型。

## 是什么

结构化数据的核心特征是**先定结构，再填数据**：

- 数据以**行（记录）和列（字段）**的形式存储
- 每个字段有明确的数据类型（整数、字符串、日期等）和长度限制
- 通过 SQL 实现高效查询、聚合、关联分析

典型例子：银行交易表（时间、金额、账户号、交易类型）、ERP 订单表、用户信息表。

## 为什么重要

- **AI 应用的基础数据源**：Fine-tuning 的训练数据、RAG 的文档元数据、用户画像都可能是结构化数据
- **与 LLM 的结合**：Text-to-SQL（自然语言转数据库查询）是 LLM 的热门应用方向，让非技术人员也能"问"数据库
- **数据分析基石**：在企业数据总量中虽只占约 20%，但价值密度最高，是 BI、报表、风控的基础

## 关键要点

- **存储系统**：MySQL、PostgreSQL、Oracle 等关系型数据库
- **典型操作**：CRUD（增删改查）、JOIN（多表关联）、GROUP BY（分组聚合）、索引优化
- **与半结构化/非结构化的关系**：企业数字化程度越高，三类数据越需要协同——结构化数据做"骨架"，半结构化做"关节"，非结构化做"血肉"

## 相关概念

- [[半结构化数据]] — 介于结构化和非结构化之间（JSON/XML/日志）
- [[非结构化数据]] — 文本、图像、音视频等无固定格式的数据
- [[LLM 大型语言模型]] — LLM 的核心输入（文本）是非结构化的，但输出可以是结构化的（Function Calling / JSON Mode）
