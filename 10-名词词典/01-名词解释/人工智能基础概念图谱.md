          │

## 关键区分

| 概念 | 定义 | 包含关系 |
| --- | --- | --- |
| AI | 模拟人类智能的计算机系统 | 最上层，包含一切 |
| ML | 从数据中自动学习，无需显式编程 | AI 的子集 |
| DL | 使用多层神经网络的 ML 方法 | ML 的子集 |
| GenAI | 能够创造新内容的 AI | DL 的应用方向之一 |
| LLM | 在海量文本上训练的大规模语言模型 | GenAI 在文本领域的核心形态 |

## 学习路线

1. **AI 基础认知** → 了解 AI、ML、DL 的层次关系
2. **Python + DL 基础** → 用 PyTorch 跑通一个简单的神经网络
3. **LLM 核心概念** → 理解 Token、Embedding、Attention、Transformer
4. **大模型开发实践** → Prompt 工程 → RAG → Agent → 微调 → 部署
5. **工程化与落地** → API 设计、成本控制、安全、可观测性
