# 提示词工程（Prompt Engineering）

> 一门通过设计、优化和系统化管理输入提示（Prompt），以最大化发挥 LLM 能力、控制输出质量的技术实践。

## 是什么

Prompt Engineering 的本质是**用自然语言给模型编程**。与传统的代码编程不同，它的"代码"是文本指令、示例和上下文结构的组合，它的"调试"是对措辞、顺序和格式的反复实验。

一个完整的 Prompt 通常包含四层结构：
1. **系统指令（System Prompt）**：定义角色、规则和输出格式（如"你是一个严谨的医学顾问"）
2. **上下文（Context）**：提供完成任务所需的背景知识（如检索到的文档片段）
3. **用户输入（User Query）**：用户的具体问题
4. **输出指引**：指定回复格式、风格、长度等约束

## 为什么重要

- **成本杠杆**：一个精心设计的 Prompt 能让 GPT-3.5 达到近似 GPT-4 的效果，直接省 10-20 倍 API 费用
- **能力放大器**：LLM 本身没有"用心思考"的机制，Prompt 是唯一引导它往正确方向推理的工具
- **工程化基础**：当 Prompt 从"个人经验"变成"可测试、可版本管理、可复用的模板"，AI 应用才真正可维护

## 关键要点

- **两大核心原则**：① 写清楚指令（分隔符、结构化、示例）② 给模型思考时间（逐步推理）
- **经典技巧**：Zero-shot CoT（加一句"Let's think step by step"）、Few-shot（给 2-3 个示例）、Chain of Thought（展示推理过程）、Self-Consistency（多条推理链投票）
- **安全不可忽略**：Prompt 同时也是攻击面——注入攻击、越狱、私有数据泄露，需要从输入过滤到输出校验的多层防御

## 相关概念

- [[System Prompt]] — Prompt 的"人格"层，在会话中持续生效且优先级最高
- [[思维链 Chain-of-Thought]] — 让 LLM 展示逐步推理的核心技巧
- [[In-Context Learning]] — 通过 Prompt 中的示例让模型学会新任务，无需微调
- [[Prompt 注入]] — 恶意用户通过输入改写系统指令的安全威胁
