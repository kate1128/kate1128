# 结构化输出（Structured Output）

> 让 LLM 按照预定义格式（JSON、XML 等）而非自由文本输出内容，使下游代码能够**可靠地解析和处理**模型的回复。

## 是什么

默认情况下，ChatGPT/Claude 输出的是自然语言文本——对人类友好，但机器处理困难。结构化输出强制模型按照指定 Schema 返回数据：

**自由文本**：
```
小明，28岁，北京，软件工程师
```
**结构化输出（JSON）**：
```json
{
  "name": "小明",
  "age": 28,
  "city": "北京",
  "job": "软件工程师"
}
```

实现方式有两种：
- **JSON Mode**：在请求中开启，模型保证输出合法 JSON（但不保证字段名和结构）
- **Function Calling / Structured Outputs**：定义 JSON Schema，模型保证输出严格匹配 Schema（OpenAI 2024 年推出的 Structured Outputs 功能，合规率接近 100%）

## 为什么重要

- **生产级可靠性的基石**：自然语言输出用正则解析是"猜"——一个换行符变化就能让解析崩掉。结构化输出让 AI 应用真正可工程化
- **链式调用的前提**：当 LLM A 的输出要作为 LLM B 的输入时，必须保证格式一致性
- **Agent 的基础能力**：Agent 的工具调用依赖模型输出精确的函数名和参数

## 关键要点

- **从"祈祷"到"保证"**：早期靠 Prompt 说"请返回 JSON"——模型经常在 JSON 外面包一段废话。现在 Function Calling 和 Structured Outputs 在 API 层面保证格式正确
- **OpenAI Structured Outputs**（2024）：支持定义精确的 JSON Schema，合规率从 ~85% 提升到 100%
- **常见应用**：信息抽取（从邮件中提取姓名、日期）、数据分类、表单自动填充、API 响应格式化
