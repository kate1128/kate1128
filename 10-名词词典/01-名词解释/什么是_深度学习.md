# 深度学习（Deep Learning）

> 机器学习的一个分支，使用**多层神经网络**自动从数据中提取层次化特征，在图像、语音、文本等领域达到了超越传统方法的效果。

## 是什么

"深度"指的是神经网络的**层数多**（几十到上千层）。每一层负责提取不同抽象级别的特征：

- 图像任务中：浅层提取边缘/颜色 → 中层提取纹理/形状 → 深层提取"眼睛""车轮"等语义概念
- 文本任务中：浅层学习词法 → 中层学习句法 → 深层学习语义和推理

核心训练流程：
1. **前向计算**：数据从输入层逐层往后算，得到预测结果
2. **损失计算**：比较预测结果和真实答案的差距（Loss Function）
3. **反向传播**：从输出层往回计算每一层的梯度（链式法则）
4. **参数更新**：用梯度下降（SGD/Adam）更新权重，让下次预测更准
5. **迭代收敛**：重复 1-4，直到 Loss 不再下降

## 为什么重要

- **LLM 的技术根基**：GPT、Claude、Gemini 等全部是深度学习模型（Transformer 架构）
- **表征学习**：深度学习最大的突破在于模型能自动学到"好的表示"——不需要人工设计特征，海量数据 + 大算力驱动
- **通用性**：同一种架构（如 Transformer）可以同时用于文本（GPT）、图像（ViT）、音频（Whisper）、视频（Sora）
- **Scaling Law**：实验表明，模型规模、数据量、算力越大，性能越好——这是 LLM 军备竞赛的理论基础

## 关键要点

- **经典架构**：CNN（图像）、RNN/LSTM（序列）、Transformer（现在统治一切）、扩散模型（图像生成）
- **训练 vs 推理**：训练需要 GPU 集群跑数周，推理只需单卡甚至 CPU
- **GPT 是深度学习**：GPT 的全称是 Generative Pre-trained Transformer——用深度学习做生成、预训练、基于 Transformer 架构
- **为什么现在爆发**：算法（Transformer 2017）+ 算力（GPU 集群）+ 数据（互联网级语料）三要素同时成熟
